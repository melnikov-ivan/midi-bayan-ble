# Подключение регистра сдвига 74HC165N

## Распиновка микросхемы 74HC165N

```
        ┌─────────┴─────────┐
     PL │ 1                16│ VCC
     CP │ 2                15│ CE (Clock Enable)
     D3 │ 3                14│ D7
     D2 │ 4                13│ D6
     D1 │ 5                12│ D5
     D0 │ 6                11│ D4
     Q1 │ 7                10│ Q7' (для каскадирования)
    GND │ 8                 9│ Q7 (последовательный выход)
        └───────────────────┘
```

## Основные выводы

| Пин | Название | Описание |
|-----|----------|----------|
| 1 | PL | Parallel Load (загрузка параллельных данных) |
| 2 | CP | Clock Pulse (тактовый сигнал) |
| 3-6 | D0-D3 | Параллельные входы (младшие биты) |
| 7 | Q1 | Внутренний выход |
| 8 | GND | Земля |
| 9 | Q7 | Последовательный выход (MSB) - основной выход для чтения |
| 10 | Q7' | Инвертированный выход Q7 (для каскадирования) |
| 11-14 | D4-D7 | Параллельные входы (старшие биты) |
| 15 | CE | Clock Enable (обычно к GND) |
| 16 | VCC | Питание (+3.3V или +5V) |

**Примечание:** Параллельные входы D0-D3 находятся на пинах 3-6 (Q5-Q2).

## Подключение кнопок/переключателей

Каждая кнопка подключается между соответствующим входом D0-D7 и GND:

```
VCC (+3.3V)
  │
  │
  ├───[10kΩ]───► D0 ────┐
  │                     │
  ├───[10kΩ]───► D1 ────┤
  │                     │
  ├───[10kΩ]───► D2 ────┤
  │                     │
  ├───[10kΩ]───► D3 ────┤
  │                     │
  ├───[10kΩ]───► D4 ────┤
  │                     │
  ├───[10kΩ]───► D5 ────┤
  │                     │
  ├───[10kΩ]───► D6 ────┤
  │                     │
  └───[10kΩ]───► D7 ────┤
                        │
                   ┌────┴────┐
                   │ Кнопка  │
                   └────┬────┘
                        │
                       GND
```

**Примечание:** Подтягивающие резисторы 10kΩ обеспечивают HIGH уровень на входах, когда кнопка не нажата. При нажатии кнопки вход подключается к GND (LOW).

## Каскадное подключение (несколько регистров)

Для чтения более 8 битов можно подключить несколько регистров последовательно:

```
CircuitPython Board
    │
    ├─── PL ────► PL (регистр 1) ────► PL (регистр 2) ────► ...
    ├─── CP ────► CP (регистр 1) ────► CP (регистр 2) ────► ...
    └─── Q7 ◄─── Q7 (пин 9, регистр 1) ◄─── Q7' (пин 10, регистр 2) ◄─── ...
```

**Важно:** При каскадировании:
- Q7' (пин 10) первого регистра подключается к Q7 (пин 9) следующего регистра
- Данные сдвигаются от первого регистра к последнему
- Чтение происходит последовательно: сначала младший регистр, затем старший

### Детальная схема каскадирования

```
CircuitPython Board
    │
    ├─── PL ────┬───► PL (пин 1, регистр 1)
    │           └───► PL (пин 1, регистр 2)
    │
    ├─── CP ────┬───► CP (пин 2, регистр 1)
    │           └───► CP (пин 2, регистр 2)
    │
    └─── Q7 ◄─── Q7 (пин 9, регистр 1) ◄─── Q7' (пин 10, регистр 2)
                                                      │
                                                      └───► Q7 (пин 9, регистр 2)
```

**Направление данных:** При чтении данные из регистра 2 сдвигаются в регистр 1, затем из регистра 1 в микроконтроллер.

## Пример кода подключения

```python
import board
from keyboard import ShiftRegister74HC165

# Создание экземпляра регистра
shift_reg = ShiftRegister74HC165(
    load_pin=board.D2,   # PL (Parallel Load)
    clock_pin=board.D3,  # CP (Clock Pulse)
    data_pin=board.D4    # Q7 (Serial Output)
)

# Чтение данных
data = shift_reg.read()
print(f"Состояние кнопок: {data:08b}")
```

## Требования к питанию

- **VCC:** +3.3V или +5V (в зависимости от вашей платы CircuitPython)
- **GND:** Общая земля
- **Ток:** ~20-30 мА в активном режиме

## Важные замечания

1. **CE (Clock Enable)** - обычно подключается к GND для постоянной работы
2. **Подтягивающие резисторы** - необходимы для корректной работы входов
3. **Задержки** - в коде могут потребоваться небольшие задержки для стабилизации сигналов
4. **Каскадирование** - Q7' (пин 10) первого регистра подключается к Q7 (пин 9) следующего регистра. При чтении сначала читаются данные из последнего регистра в каскаде, затем из предыдущих
